# Implémentation approuvée — 11 novembre 2026

Objectif : une réplique française fidèle dans C:\Dev\dictee-magique, locale et prête
à publier, sans publier le dépôt ou la démo pendant cette intervention.

1. Valider MAME 0.289 / Emscripten 3.1.74 avec la ROM française avant la façade.
   Le banc d'essai vérifie import, démarrage, segments, touches et audio réel.
2. Séparer le validateur ZIP et son manifeste, le pont moteur, l'interface et les
   contrôles d'entrée. Tester les archives synthétiques sans ROM dans le dépôt.
3. Après démarrage validé, dessiner la coque française rouge/jaune en CSS/SVG,
   restituer les segments réels et connecter les commandes souris/clavier/tactile.
4. Vérifier partie de dictée, répétition, autres modes, focus, annulation tactile,
   redémarrage et volume. Contrôler les vues desktop/mobile et le build statique.
5. Livrer README français, scripts reproductibles, notices et inventaire de sources.
   Vérifier l'absence de ROM dans les fichiers distribuables. Aucun commit ni push.

Le code applicatif original est MIT. La ROM reste hors du projet publiable et les
licences MAME sont conservées. Pas de synthèse vocale de remplacement, de serveur
applicatif, de compte, de télémétrie ni de cartouche d'extension en v1.

## Évolution autorisée

Le 11 novembre 2026, la publication GitHub Pages, la mémorisation locale de la ROM
et Marche avec activation du son ont été autorisées. Ces décisions remplacent les
restrictions de publication et de stockage de la version initiale. Les voix modernes
